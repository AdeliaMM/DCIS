# DCIS
Решение письменного задания для кафедры КИС МФТИ ФПМИ


Автор: Мухаметдинова Аделия Маратовна
Задание: Задание №4 "Старая карта"
Компиляция: Файл целостно компилируется в готовое решение при наличие необходимых библиотек

Дополнительная информация: Решение принимает карту ровно в том же формате, что и пример:
MAP
day_cost 4
entrance ШАХТА
vertex ШАХТА 0
vertex ЗАЛ-А 10
vertex ЗАЛ-Б 20
vertex ЗАЛ-В 12
edge х1 ШАХТА ЗАЛ-А 0.4
edge х2 ЗАЛ-А ЗАЛ-Б 0.9
edge х3 ШАХТА ЗАЛ-В 0.9
END
Считается, что вход entrance будет заявлен до ввода вершин, что среди вершин нет совпадающих имен, что ребра будут задаваться для существующих вершин единоразово.
